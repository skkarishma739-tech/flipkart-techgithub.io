1️⃣ Project Overview

EduConnect AI is a premium, single-file educational platform built with pure HTML, CSS, and JavaScript. It provides an integrated system for student-faculty interaction, AI-powered guidance, mentorship programs, and sponsor rewards.

Key Statistics

Aspect Details
File Type Single HTML File (.html)
Dependencies None (Fully Self-Contained)
Framework Vanilla HTML5, CSS3, JavaScript
Features Authentication, Chat, AI Support, Payments, Sponsors
Responsive Yes, Mobile & Desktop Optimized

Application Views (4 Main Pages)

View ID Purpose Status

The application uses localStorage for persisting user state and chat history across sessions. All data is stored client-side for privacy and instant access.

9️⃣ Chat & AI Logic

Chat Architecture

  • Sidebar: Faculty contact list
  • Main: Chat interface with messages
  • Header: Active contact info & AI badge
  • Input: Message box with file upload

Message Flow

User Input → Message Sent → Append to Chat ↓ Faculty Online? YES → Direct Response ↓ Faculty Offline → Trigger AI Response

AI Response Logic

When faculty is offline, the AI Assistant analyzes user messages for keywords (error, help, scholarship) and provides contextual responses. Can also analyze uploaded images using "AI Vision."

Key Functions

appendMessage(type, content, avatar, name) selectContact(name, isOnline, avatar) sendMessage() generateAIResponse(userText) sendImageMessage(imgUrl, fileName)

🔟 Payment & Sponsor System

Payment Flow

1. User clicks "Premium Sponsor" button 2. Payment modal opens with QR code 3. User "scans" (or confirms payment) 4. processPayment() is called 5. Prize modal shows success 6. activateSponsorMode() unlocks features 7. UI updates with gold theme

Sponsor Mode Activation

Once activated via activateSponsorMode():
  • User name shows "VIP Sponsor" badge
  • VIP Sponsor tab appears in navbar
  • Premium content unlocks in dashboard
  • VIP subject button appears in chat
  • Priority mentorship available

Integration Points
